- Support custom theming like btop.
- Support modal editing: `i` enters note-insert mode, with `hjkl` still used for
  navigation; `Esc` returns to normal mode. Normal mode supports counted motions:
  `16j` moves 16 rows down, `2l` moves two tracks right.
- Switch panel views with the F keys:
  - `F1`: pattern editor.
  - `F2`: song arrangement.
  - `F3`: mixer.
  - `F4`: instrument editor.
- Support `:` commands, like Vim/Helix.
